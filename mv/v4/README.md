# 例片 v4：铅笔原画 × riso 孔版印刷（4K 60 帧）

按用户反馈，把第一轮的 04（riso 印刷）和 05（原画手稿）两种画风合进现有的故事结构。

| 段落 | 时间 | 画风 |
|---|---|---|
| 片假名四连（故事段） | 3:30–3:46 | 05 铅笔原画：作画用纸、蓝铅笔打底、石墨正稿、定位孔、摄影表批注。ボク是粉色彩铅，キミ是薄荷彩铅。 |
| 静音 | 3:46–3:50 | 最后一张原画翻走，剩一张空白作画纸。红笔写「無音 三・七秒」，铅笔裂纹爬满纸面。 |
| 最终副歌 | 3:50–4:06 | 纸张碎开，进入 04 riso 印刷：荧光粉 / 薄荷 / 蓝 / 黑四块印版，真实网点。 |

## 关键做法

- **原画**：codex 以用户的角色设定图和キミ设定图为参考生成（`prompts/`，原图在 `src_art/`）。`tools/genga4k.py` 处理成 4K 扫描件：
  - 绿色系的彩铅调向薄荷青；
  - 模拟石墨在纸纹上断开的颗粒；
  - 同时生成一张带定位孔的空白作画纸。
- **歌词（故事段）**：用铅笔纹理直接填充字形，逐字"写"出来，按每秒 12 次轻微抖动。
  - 片假名是红色彩铅（Yusei Magic）；
  - 句子是石墨（Klee One），翻译是红笔批注（Long Cang）。
- **换镜**：下一张画先透过纸显出来（透写台亮灯），然后上层纸从顶部翻走。新句子开始时纸张轻轻一顿。
- **riso**：`tools/riso.py` 把 v3 的平涂画分色成四块印版。
  - 每块印版是独立的网点层（不同网角、墨量不均、纸白斑点）；
  - 线稿走黑版。
- **渲染**：渲染时四块印版逐块正片叠底：
  - **套色错位**：每块印版的偏移跟着底鼓、军鼓和小节头跳动；
  - **镜头切换**：3:50 那一下错位最大；
  - **镜像倒影**：反拍时 キミ那半边粉 / 薄荷两块印版互换颜色，她一瞬间变成ボク的配色；
  - **文字**：大字从所有印版里镂空（露出纸白），再叠印一层错位的强调色；
  - **字幕**：贴在镂空出来的纸条上。
- **规格**：3840×2160，60fps，逻辑排版 1920×1080、以 2 倍绘制。`tools/capture4k.js` 把浏览器逐帧画面直接送进 ffmpeg。

## 重新出片

1. `python3 -I tools/genga4k.py <原画.png> art/g1.jpg ...`
2. `python3 -I tools/riso.py <v3 平涂 4K.png> art/c1 ...`
3. 在 `render/` 起本地 HTTP 服务（需要 `art/`、`lyrics.js`、`drums.js`），然后运行 `node tools/capture4k.js OUT 60 210.0 246.0 3`。
4. 用 ffmpeg concat 合并分段，并混入音频。
